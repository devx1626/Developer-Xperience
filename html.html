Introduction to HTML

What are Markup Languages?

A markup language is a system for defining the structure, presentation, and/or purpose of content within a digital document so computer programs can interpret and display the content correctly. Markup languages encode text using specific vocabulary, symbols, and/or syntax rules. For example, the <h1> tag in HTML communicates that the enclosed text is a top-level heading. Search engines can use this information to better understand the subject matter of your page. While browsers can use this information to apply the relevant styling. Markup languages can:

  1. Make your website more search engine-friendly
  2. Ensure your content displays consistently across different technologies
  3. Improve website accessibility

Frontend Development

Front-end development is designing and creating the front end or design side of a website, application, or other development project. When you think of a website you like to visit, you might picture the colors, logo, and other design elements you see when navigating the home page. You can click links that take you to other pages on the website, each containing text, images, links to navigate to different pages, buttons to click, menus that expand when you hover your pointer over them, and more. All of these elements allow you, the user, to find the information you're looking for in an intuitive and pleasant way. While a back-end developer is the professional who writes the base code that allows the website to function, a front-end designer designs these elements so that users can have a positive experience while engaging with the website.

HTML

HTML (HyperText Markup Language) is the most basic building block of the Web. It defines the meaning and structure of web content. Other technologies besides HTML are generally used to describe a web page's appearance/presentation (CSS) or functionality/behavior (JavaScript). "Hypertext" refers to links that connect web pages to one another, either within a single website or between websites. Links are a fundamental aspect of the Web. By uploading content to the Internet and linking it to pages created by other people, you become an active participant in the World Wide Web.

CSS

CSS (Cascading Style Sheets) is a language that describes the style of an HTML document. CSS describes how HTML elements should be displayed. This tutorial will teach you CSS from basic to advanced. CSS saves a lot of work. It can control the layout of multiple web pages all at once.

JavaScript

JavaScript (JS) is a lightweight interpreted (or just-in-time compiled) programming language with first-class functions. While it is most well-known as the scripting language for Web pages, many non-browser environments also use it, such as Node.js, Apache CouchDB and Adobe Acrobat. JavaScript is a prototype-based, garbage-collected, dynamic language, supporting multiple paradigms such as imperative, functional, and object-oriented.

How The Web Works

What is HTTP?

The Hypertext Transfer Protocol (HTTP) is the foundation of the World Wide Web, and is used to load webpages using hypertext links. HTTP is an application layer protocol designed to transfer information between networked devices and runs on top of other layers of the network protocol stack. A typical flow over HTTP involves a client machine making a request to a server, which then sends a response message.

Domain Name

Domain names are human-friendly web addresses (e.g., google.com) substituting numerical IP addresses. Comprise second-level ("google") and top-level (.com) domains. Registered through registrars, essential for branding and online presence. DNS translates names to IP addresses for accessibility.

Hosting

Web hosting stores website files on servers, making sites accessible online. Types include shared (multiple sites per server) and dedicated (exclusive server) hosting. Providers offer additional services like email, domains, and security certificates. Critical for website performance and accessibility.

DNS

DNS (Domain Name System) translates human-readable domain names into IP addresses through a global, decentralized server network. Enables easy internet navigation by converting names like www.example.com to numeric addresses browsers can connect to.

Browsers

Web browsers request and display websites by interpreting HTML, CSS, and JavaScript. Use rendering engines (Blink, Gecko) for display and JavaScript engines (V8) for code execution. Handle security, bookmarks, history, and user interactions for web navigation.

Search Engine Optimization (SEO)

Search Engine Optimization, or SEO, is the practice of improving your website to increase its visibility when people search for products or services related to your business in search engines like Google. The better visibility your pages have in search results, the more likely you are to garner attention and attract prospective and existing customers to your business. A related concept, Generative Engine Optimization (GEO), focuses on optimizing content for AI-powered search experiences, ensuring your information is accurately and effectively presented in AI-generated summaries and responses;

Your First HTML File

Creating your first HTML file is simple. Follow these steps:

  1. Choose a text editor. Any basic editor (e.g., VS Code, Sublime Text, Notepad++) will work.
  2. Write the skeleton. Use the standard HTML5 boilerplate: 
            <!DOCTYPE html>
                  <html lang="en">
                    <head>
                      <meta charset="UTF-8">
                      <meta name="viewport" content="width=device-width, initial-scale=1.0">
                      <title>My First Page</title>
                    </head>
                    <body>
                      <h1>Hello, World!</h1>
                    </body>
                  </html>

Save the file as index.html (the extension .html is required). Open it in a browser by double clicking the file or dragging it into any browser window. You should see the heading “Hello, World!”.

This section teaches how to create a minimal HTML file, save it with the .html extension, and view it in a browser.

HTML Document Structure

DOCTYPE Declaration

The <!DOCTYPE html> declaration represents the document type and helps browsers render the page correctly. It must be the very first line in your HTML file, before the <html> tag. In HTML5, the declaration is simple and case-insensitive.

Resource: MDN: Doctype declaration

<html> Element

The <html> element is the root of an HTML page. All other elements must be descendants of this element. The lang attribute should be set on this element to declare the page's language, which is essential for screen readers and search engines.

Resource: MDN: html element

<head> Element

The <head> element contains machine-readable information about the document, such as <meta> tags, the <title>, links to stylesheets, and scripts. Content inside <head> is not directly displayed in the browser window.

Resource: MDN: head element

<body> Element

The <body> element contains the visible page content — text, images, videos, forms, and other HTML elements. There should be only one <body> per document, and it is a direct child of <html>.

Resource: MDN: body element

Meta Charset

The <meta charset="UTF-8"> tag sets the character encoding for the HTML document. UTF-8 supports all characters from all human languages and is the preferred encoding for modern web development.

Resource: MDN: Meta charset

Viewport Meta Tag

The <meta name="viewport" content="width=device-width, initial-scale=1.0"> tag ensures your page is properly scaled on mobile devices. This is essential for responsive design and mobile-first development.

Resource: MDN: Viewport meta tag

<title> Element

The <title> element defines the title of the document, shown in the browser's title bar or tab. A good title is descriptive, concise (50-60 characters), and includes relevant keywords for SEO.

Resource: MDN: title element

Semantic Document Structure

Proper use of semantic elements (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>) helps search engines and assistive technologies understand your page structure. Semantic HTML also improves accessibility and SEO.

Resource: MDN: Semantic HTML guide

HTML Text Elements

Headings (<h1>-<h6>)

HTML headings define six levels of section headings. <h1> is the most important and typically used for the main title, while <h2>-<h6> denote subsections. Use headings hierarchically and skip levels sparingly. Only one <h1> per page is recommended.

Resource: MDN: HTML headings

Paragraphs (<p>)

The <p> element defines a paragraph of text. Avoid using <p> for line breaks — use CSS margins or the <br> element sparingly for actual line breaks within poetry or addresses.

Resource: MDN: Paragraph element

Text Formatting

HTML provides several semantic elements for text formatting:

  • <strong> — strong importance (preferred over <b> for semantic meaning)
  • <em> — emphasized text (preferred over <i>)
  • <abbr> — abbreviations and acronyms with title attribute
  • <blockquote> — long quotations
  • <q> — inline quotations
  • <code> — inline code
  • <del> — deleted text
  • <ins> — inserted text
  • <mark> — highlighted text

Resource: MDN: HTML elements reference

Line Breaks (<br>)

The <br> element produces a line break in text. Use it for poems, addresses, or other actual line-break situations — not for adding spacing between paragraphs (use CSS margin instead).

Resource: MDN: Line break element

Horizontal Rule (<hr>)

The <hr> element represents a thematic break between paragraph-level elements — ideal for separating sections of a document. It is a self-closing tag and does not require a closing tag.

Resource: MDN: The hr element

HTML Links

Anchor Element (<a>)

The <a> element creates hyperlinks to other pages, files, or locations within the same page. The href attribute specifies the link destination. Always include descriptive link text (avoid "click here" or "read more" alone).

Resource: MDN: Anchor element

Absolute vs Relative URLs

Absolute URLs include the full address (e.g., https://www.example.com/page) and work from any context. Relative URLs are relative to the current page's location (e.g., about.html, ../contact/index.html) and are better for internal linking and portability.

Resource: MDN: Absolute vs relative URLs

Link Targets and Security

When opening links in a new tab, always include target="_blank" and rel="noopener noreferrer" to prevent the new page from accessing the original page via window.opener, improving security.

Resource: MDN: Link types

Named Anchors (Internal Linking)

Create intra-page links using the id attribute on any element and a corresponding fragment identifier in the href (e.g., <a href="#section-2>). This improves navigation for keyboard users and long documents.

Resource: MDN: Internal links

Accessible Link Text

Link text should be descriptive enough to make sense out of context. Screen readers often list all links on a page, so "click here" is unhelpful, while "View our HTML course syllabus" is clear and useful.

Resource: WAI-ARIA Authoring Practices: Links

HTML Images and Media

Images (<img>)

The <img> element embeds images into a page. The src attribute specifies the image source, and the required alt attribute provides alternative text for screen readers and when images fail to load. Descriptive alt text is essential for accessibility.

Resource: MDN: img element

Figure and Caption (<figure>, <figcaption>)

Use the <figure> element to group an image, diagram, code snippet, or other media with its caption, wrapped in <figcaption>. This associates the media with its description semantically.

Resource: MDN: figure element

SVG Graphics

Scalable Vector Graphics (SVG) can be embedded directly using <svg> elements or as image sources. SVG graphics are resolution-independent and ideal for icons, logos, and illustrations.

Resource: MDN: Images in HTML

Video and Audio

The <video> and <audio> elements embed media files. Always include controls for user interaction, and provide poster images for video. For accessibility, add <track> elements for captions and subtitles.

Resource: MDN: Video and audio content

HTML Tables

Table Element (<table>)

The <table> element displays tabular data. Use tables for data that naturally fits in rows and columns — not for page layout. Thead, tbody, and tfoot can be used to structure the table.

Resource: MDN: table element

Table Rows and Cells (<tr>, <td>, <th>)

<tr> defines a table row, <td> defines a standard cell, and <th> defines a header cell. Header cells are typically bold and centered and should be used for row or column headers.

Resource: MDN: td element

Table Headers (<th> scope attribute)

The scope attribute on <th> elements defines whether a header applies to a row, column, or group of rows/columns. Values include row, col, rowgroup, and colgroup. This is crucial for screen reader navigation of tables.

Resource: MDN: th scope attribute

Accessible Tables

For complex tables, use for a summary, for header rows, and id/headers attributes to associate data cells with their headers. Never use

for page layout — it harms accessibility and SEO.

Resource: MDN: Accessible tables

HTML Forms

Form Element (<form>)

The <form> element collects user input and sends it to a server. The action attribute specifies the URL to send data to, and method defines the HTTP method (usually GET or POST).

Resource: MDN: form element

Form Inputs (<input>)

The <input> element is the most versatile form element. The type attribute determines the input kind (text, email, password, number, checkbox, radio, file, etc.). Always include a corresponding <label>.

Resource: MDN: input element

Label Association

Associate text labels with form inputs using the for attribute on the <label> matching the id on the input, or by wrapping the input inside the <label>. This improves accessibility and toggles focus when clicking the label.

Resource: MDN: label element

Form Controls: Textarea, Select, Button

<textarea> for multi-line text, <select> for dropdown lists, and <button> for submit/reset actions. Each should have a descriptive label for accessibility.

Resource: MDN: textarea | MDN: select | MDN: button

Form Validation

Use HTML5 input types and attributes (required, min, max, pattern) for built-in client-side validation. Always provide server-side validation as well, as client-side can be bypassed.

Resource: MDN: How forms work

HTML5 Semantic Elements

Semantic Document Landmarks

HTML5 introduced semantic elements that describe the purpose of content:

  • <header> — introductory content or navigational links
  • <nav> — navigation links
  • <main> — primary content of the document
  • <section> — thematic grouping of content
  • <article> — independent, self-contained content
  • <aside> — content tangentially related (sidebars, callouts)
  • <footer> — footer information, copyright, related links

Resource: MDN: HTML5 sectioning elements

When NOT to Use Semantic Elements

Avoid using semantic elements solely for styling purposes. Use

or when no semantic meaning is appropriate, and style with CSS. Overusing semantic elements can confuse assistive technologies and Outline algorithms.
