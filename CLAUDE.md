# Project Context

This is an HTML/CSS project containing icon assets and web components for the Dev portfolio.

## Structure

- `index.html` - Main HTML page
- `main.css` - Primary stylesheet
- `html.html` - HTML reference/documentation
- `*.png` - Icon assets (android-chrome, apple-touch-icon, favicon)
- `site.webmanifest` - Web app manifest

## Conventions

- Follow HTML5 semantic markup
- Use responsive design principles
- Optimize images for web (PNG assets provided at multiple resolutions)
- Accessibility: alt text provided for informative icons
- Cross-browser compatible

## Claude Code Integration

This project is configured for Claude Code workflows:
- Changes land in `claude/` branches
- Commit messages follow conventional format
- GitHub Actions can be triggered via `@claude` mentions
